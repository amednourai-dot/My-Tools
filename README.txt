# إضافة مكتبة الروايات إلى Ahmed Tools

## الملفات
- `novels.js`: واجهة المكتبة، البحث، التصنيفات، المفضلة، قارئ الفصول، وحفظ موضع القراءة.
- `novels/novels.json`: فهرس الروايات.
- خمسة ملفات JSON منفصلة، واحد لكل رواية، وبداخل كل رواية خمسة فصول.
- `service-worker.js`: نسخة محدثة من عامل الخدمة باسم cache `ahmed-tools-v5`.

## دمجها داخل مشروعك
1. ارفع مجلد `novels` كاملًا إلى جذر مستودع `My-Tools` بجانب `index.html`.
2. ارفع `novels.js` إلى جذر المستودع.
3. استبدل ملف `service-worker.js` الحالي بالملف الموجود هنا.
4. في نهاية `index.html`، بعد سطر `script.js` وقبل `</body>`، أضف:
   `<script src="novels.js"></script>`
5. احفظ التعديلات وانتظر اكتمال GitHub Pages، ثم افتح التطبيق بالإنترنت مرة واحدة حتى تُحمّل ملفات الروايات وتُخزّن.
6. إذا لم تظهر المكتبة فورًا، أغلق التطبيق وافتحه مجددًا أو حدّث الصفحة.

## ملاحظات
- المكتبة تُضاف عبر ملف مستقل لتجنب استبدال `script.js` الكبير أو التأثير في أدواته.
- القراءة والتقدم والمفضلة تُحفظ محليًا في `localStorage` على الجهاز.
- لا توجد قاعدة بيانات ولا تسجيل دخول.
- النصوص الموجودة أصلية ومكتوبة لهذه المكتبة.
- لضمان العمل دون اتصال، يجب رفع كل ملفات `novels` بالأسماء نفسها المذكورة في عامل الخدمة.
